# ServiceTracker

Приложение для учёта сервисных работ и отслеживания маршрутов технических специалистов.

## Функции

- GPS-трекер маршрута (1000 сум/км)
- Интерактивная карта Узбекистана с точками обслуживания
- Добавление точек по координатам
- История посещений с фотоотчётами
- Статус оборудования (работает/не работает)
- Два типа аккаунтов: специалист и руководитель

## Быстрый старт

### 1. Создать проект Supabase

1. Зарегистрируйтесь на [supabase.com](https://supabase.com)
2. Создайте новый проект
3. Перейдите в **SQL Editor** и выполните содержимое файла `supabase/schema.sql`
4. Скопируйте **Project URL** и **anon key** из Settings → API

### 2. Настроить окружение

Отредактируйте файл `.env`:

```
VITE_SUPABASE_URL=https://ваш-проект.supabase.co
VITE_SUPABASE_ANON_KEY=ваш-anon-key
```

### 3. Запустить

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173` на ПК или `http://<ваш-ip>:5173` на телефоне (один Wi-Fi).

### 4. Установить как PWA

На телефоне: откройте сайт → меню браузера → "Добавить на главный экран".

## Роли

| Роль | Права |
|------|-------|
| **Специалист** | Добавление точек, GPS-трекер, отчёты, фото |
| **Руководитель** | Просмотр карты, маршрутов, статистики |

## GPS Трекинг

- Использует `navigator.geolocation.watchPosition` с `enableHighAccuracy: true`
- Фильтрует GPS-выбросы (точность > 50м, скорость > 180 км/ч)
- Отправляет данные на сервер каждые 10 секунд
- Wake Lock API предотвращает засыпание экрана

## Деплой

### Vercel (бесплатно)

1. Загрузите код на GitHub
2. Подключите репозиторий на [vercel.com](https://vercel.com)
3. Добавьте переменные окружения `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`
4. Деплой автоматический

### Netlify (бесплатно)

1. Загрузите код на GitHub
2. Подключите на [netlify.com](https://netlify.com)
3. Build command: `npm run build`, Publish directory: `dist`
4. Добавьте переменные окружения
